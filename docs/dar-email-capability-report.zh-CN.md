# 大R邮件营销能力说明（通用·汇报版）

## 开篇备注

本文是给 Cursor 与协作方的汇报，说明大R邮件可覆盖的类型，以及每类的作用、频率与触发、目的、主CTA、禁区和依赖。

- 本文不是定稿邮件，也不是拍板材料。
- 文中示意文案不等于定稿，不直接用于发送。
- 本次未发信、未导名单、未改邮件后台。
- 金额、门槛、折扣等数字一律不写；缺少依据的项写「未检测到」。

## 通用口径

1. **范围**：不是试点，各站通用。依赖齐备后，各类型、各站可并行准备，发送窗口错开即可。
2. **主通道**：营销邮件群发后台，可群发；名单可导出；目前已有召回名单。
3. **创作者路线**：网站不做创作者路线。官方社媒最多发用户作品，且须为 SFW；大R内容多为 NSFW。邮件的「创作者邀请」整类不做，也不作为可选项保留。
4. **Max身份组**：用户买 Max 并链接 Discord 后自动分配。邮件中不提醒「去绑 DC」或「领 Max 身份组」。
5. **称呼**：统一用「高价值用户」，不用「高价值创作者」。
6. **社区承接**：用各站现有的 `💎丨max-chat`（或对等的 Max 频道），不新建跨站大R服。第一封不配站内弹窗。
7. **分层**：靠邮件后台的名单或标签分层，不在公开 Discord 公布门槛数字。

## 各邮件类型

### 进档感谢

> **备注**
> - 作用：告知用户已进入高价值名单，建立身份；不需要折扣也能发。
> - 频率/触发：定档后按累计付费和最近付费分档入名单；仅发未退订营销的用户；每档约留 20% 作为对照，不发首轮。
> - 目的：建立「之后上新会优先邮件预告」的预期，并承接进现有 Max 频道。

| 项 | 内容 |
|---|---|
| 对象 | 中R、大R（门槛以上） |
| 内容要点 | 感谢支持（不写金额）→ 已在高价值名单 → 之后上新提前邮件告知 |
| 主CTA | Discord 邀请进入现有 `💎丨max-chat`，带 UTM；不引到泛首页；不另开站内弹窗 |
| 禁区 | 不写付费金额或档位数字；不提醒绑 DC、领身份组；不硬推销；不承诺未批准的折扣或加赠 |
| 依赖 | 已有群发后台和方向共识；缺打码样表与门槛数字 |

示意（非定稿，不发）：感谢支持。你已在高价值用户名单，之后上新会优先邮件预告，欢迎进入现有 Max 专属频道。

### 上新抢先约48h

> **备注**
> - 作用：在全站开放前，给名单一个真正专属的短窗抢先体验。
> - 频率/触发：绑定具体上新或活动节点才发，没有节点不发；可配同一 campaign 的短窗弹窗。
> - 目的：强化名单权益感，带动试用和回站。

| 项 | 内容 |
|---|---|
| 主CTA | 制作页或活动页试用，带 UTM；写明窗口结束后全站开放的时间 |
| 禁区 | 无节点不发；不写未核定的限时折扣；不提醒绑 DC；不暗示永久专属 |
| 依赖 | 缺具体上新节点；后台能否做真专属窗口未检测到 |

示意（非定稿，不发）：全站开放前，高价值名单约 48 小时抢先体验；窗口结束后对全站开放。

### 7天沉默召回

> **备注**
> - 作用：对累计付费达门槛、但 7 天及以上未登录的高价值用户做回流触达。
> - 频率/触发：基于现有召回名单或分层结果推进；留 10–20% 作为对照；与进档感谢错开发送，可并行准备。
> - 目的：用具体上新或玩法给出回流理由；同批对在网大R给出对等说法。

| 项 | 内容 |
|---|---|
| 主CTA | 回站查看具体上新或制作入口，带 UTM；可附 Max 频道链接，但不推绑身份组 |
| 禁区 | 不单靠送积分；不对在网用户不公平；不写未批准的折扣；不硬推销 |
| 依赖 | 已有召回名单和群发；缺公平感定稿口径和发送节奏 |

示意（非定稿，不发）：这段时间有具体更新（名称以当时事实为准），方便时可以回来看看。

### 黑五大R先开

> **备注**
> - 作用：节日节点对名单先开放约 48 小时，之后全站开放。
> - 频率/触发：节日节点；开窗日待排期确认。
> - 目的：节日转化，同时体现名单权益；在网用户与召回用户口径对等。

| 项 | 内容 |
|---|---|
| 主CTA | 活动页或结账页，带 UTM；邮件中的权益与结账页一致 |
| 禁区 | 商业化额度批准前不写具体折扣或加赠数字；不硬推销；不提醒绑 DC |
| 依赖 | 缺商业化额度和准确开窗日 |

示意（非定稿，不发）：节日期间高价值名单先开放约 48 小时，随后全站开放；加赠或折扣以商业化核定、且与结账页一致为准。

### 余额用完提醒

> **备注**
> - 作用：额度用尽时，提醒用户继续创作的路径。
> - 频率/触发：由「余额用完」行为事件触发；该事件接通产品与邮件后台的情况未检测到。
> - 目的：降低流失；接通后引导查看套餐或充值。

| 项 | 内容 |
|---|---|
| 主CTA | 套餐或充值入口（事件接通后启用） |
| 禁区 | 接通前不承诺自动化；不编造限时倒计时；不硬推销 |
| 依赖 | 缺「余额用完」事件接通邮件后台 |

### 活动节点邮件

> **备注**
> - 作用：按活动节奏发预告、进度、最后召集、获奖等。
> - 频率/触发：有明确活动排期才发；一条活动线最多约 4 封；大R版可先于全站。
> - 目的：带动报名、提交和回看进度。

| 项 | 内容 |
|---|---|
| 主CTA | 活动说明页的报名、提交或进度入口，带 UTM |
| 禁区 | 无排期不发；奖品未批准不写死数字；不提醒绑 DC；不推站外支付 |
| 依赖 | 缺活动排期和 UTM；有奖品时还缺奖品额度 |

### 14天未登

> **备注**
> - 作用：在 7 天召回之后做第二次沉默触达，力度递减。
> - 频率/触发：14 天及以上未登录；与 7 天序列错开。
> - 目的：二次轻触达，用户可以忽略；避免同一周重复触达。

| 项 | 内容 |
|---|---|
| 主CTA | 回站查看更新入口，带 UTM；用户可以忽略 |
| 禁区 | 不与 7 天召回同周发送；不硬推销；不提醒绑 DC；力度弱于首轮召回 |
| 依赖 | 现有召回表中是否含「最近登录日」字段未检测到 |

### 创作者邀请（整类不做）

网站不做创作者路线，社媒仅发 SFW 内容，邮件不做创作者邀请，也不作为可选项保留。本类不写主题行、主CTA 或示意。

## 通道与名单

| 通道/名单 | 说明 |
|---|---|
| 营销邮件群发后台 | 主通道，可群发 |
| Discord 💎 / Max身份组 | 买 Max 并链接 Discord 后自动分配；邮件不提醒绑 DC 或领身份组；现有 `💎丨max-chat` 承接 |
| 站内弹窗 | 第一封不配；仅抢先类邮件考虑短窗弹窗，与邮件同一 UTM |
| 召回名单 | 目前已有 |
| 进档名单 | 按站分档，各站通用；样表和门槛数字待定 |
| 对照组 | 每档约 20% 不发首轮 |

UTM 格式（示意）：`utm_source=email&utm_medium=daR&utm_campaign=<site>-<mail-id>&utm_content=<tier>`
